# btest UI (read-only workbench)

Status: shipped 2026-10-02 (read-only). Local only: `uv run btest ui` serves http://127.0.0.1:8765.

## Job

Answer three questions faster than the CLI does:

1. Which runs are worth a second look? (runs table, sortable by any metric)
2. Is a good result robust or one lucky setting? (sweep heatmap over two params)
3. Does strategy A beat strategy B over the same window? (equity overlay, metrics side by side)

It does not launch runs or edit strategies. The CLI and the editor keep those jobs.

## Pages

| Route | Shows |
|---|---|
| `#/runs` | Every run: strategy, symbols, window, params, Sharpe, CAGR, max drawdown, return, fills, holdout flag. Tick up to 4 to compare. |
| `#/runs/:id` | Figures strip, equity vs SPY (log toggle), drawdown, monthly return grid, fills, config and commit. |
| `#/compare?ids=` | Equity curves rebased to 100, metrics side by side. |
| `#/sweeps` | Every sweep. |
| `#/sweeps/:id` | Heatmap of any metric over any two grid params (others fixed by selectors), best cell outlined, edge-of-grid warning, ranked table. |
| `#/data` | Bars per symbol, first and last bar, corporate actions, holdout start. |

## Look

Dark trading-desk surface, dense, numbers first.

| Token | Hex | Role |
|---|---|---|
| ground | `#0d1118` | page |
| panel | `#141a24` | chart and table surface |
| rule | `#232c3a` | hairlines, grid |
| ink | `#e7ebf1` | primary text |
| dim | `#8b95a7` | secondary text, benchmark line |
| signal | `#f2b544` | selection, focus, best sweep cell; never data |

Series follow the validated dataviz dark slots (blue `#3987e5`, orange `#d95926`, aqua
`#199e70`, yellow `#c98500`), checked on `#141a24`. Signed figures carry a `+`/`−` sign as
well as green/red, so colour is never the only cue. Monthly returns use a blue-to-red diverging
scale through grey, with the value printed in each cell.

Type: IBM Plex Sans Condensed for interface text, JetBrains Mono for every figure (tabular).

## Build

Starlette JSON API over the existing Postgres `runs` schema and Parquet store. Static
HTML/CSS/JS with hand-written SVG charts, no build step.
