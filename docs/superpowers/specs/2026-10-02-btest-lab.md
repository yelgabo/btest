# btest lab: edit and run strategies on the website

Status: shipped 2026-10-02.

## Job

Edit a strategy in the browser, press Run (or Sweep), see the result, jump to another strategy
from a file tree like VS Code's explorer.

## Pieces

| Piece | Where | Notes |
|---|---|---|
| `lab.strategy`, `lab.strategy_version` | Postgres | Name is a path (`trend/ma_cross`); folders come from the slashes. Every save that changes code is a new version. Runs and sweeps record `strategy_version_id`. |
| `lab.job` | Postgres | Queue of run and sweep requests: spec (symbols, window, params, grid, costs), status, error with line number, result id. |
| web service | Railway | UI and API. No Alpaca keys, no bars, never executes strategy code. Parses `params = {...}` with `ast` only. |
| worker service | Railway | Owns the `/data` volume with the Parquet bars and the Alpaca keys. Ingests on first start and every weekday evening. Claims jobs with `FOR UPDATE SKIP LOCKED` and runs each in a child process. |
| child process | worker | Gets the job and code on stdin, connects as `btest_runner` (read market, write runs, nothing else), has a wall-clock limit (run 5 min, sweep 15 min) and an address-space cap. Alpaca keys and the main DB URL are stripped from its environment. |

## Safety

- Login page with a signed session cookie (`SameSite=Strict`, 14 days), 10 failed attempts per
  IP per 15 minutes then 429.
- Every non-GET API call needs the `X-Btest` header, so another site cannot post a job
  through the browser's cookie.
- Windows that reach the holdout need `spend_holdout: true`; the editor asks for it with a
  checkbox. Sweeps never reach it.

## Editor page (`#/strategies/:id`)

```
+----------------+-------------------------------------+------------------+
| STRATEGIES  +  | trend/ma_cross   v3  [Save] [Run]   | Run              |
| v trend        |                                     |  symbols, window |
|   ma_cross  *  |   code (CodeMirror, Python)         |  params (from    |
|   breakout     |                                     |  params = {...}) |
| v mean_rev     |                                     |  [x] holdout     |
|   rsi_2        |                                     | Sweep grid       |
|                +-------------------------------------+                  |
|                | Output: queued > running > result   | Recent runs      |
+----------------+-------------------------------------+------------------+
```

Cmd/Ctrl+S saves, Cmd/Ctrl+Enter saves and runs. A failing run highlights the line in the
editor.
